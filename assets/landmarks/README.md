# Personal landmarks

These transparent pixel-art PNGs were generated with the built-in image generator. Old Main and the California Tower use the supplied photographs as visual references. Each is placed through `assets/level-art/manifest.json`.

| Landscape | Landmark |
| --- | --- |
| Snow | Old Main at Utah State University |
| Desert | Delicate Arch in Arches National Park |
| Autumn | Bunker Hill Monument in Boston |
| Beach | California Tower and dome from the supplied San Diego photograph |
| Mountain | Old Faithful in Yellowstone |

The generation prompts requested recognizable silhouettes, restrained 16-bit pixel palettes, complete subjects, transparent backgrounds, and no lettering. Old Main has a light snow treatment.

Reference pages for identification and proportions include [Delicate Arch](https://www.nps.gov/arch/planyourvisit/delicate-arch.htm), [Bunker Hill Monument](https://www.nps.gov/places/bunker-hill-monument.htm), [California Tower](https://museumofus.org/exhibits/california-tower), and [Old Faithful](https://www.nps.gov/places/old-faithful-geyser.htm).
