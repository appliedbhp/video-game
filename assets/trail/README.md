# Trail sprites

- `checkpoints.png` uses 48 × 64 cells and six frames across. Each level has two rows in sequence, unlit then active. The level-art manifest supplies row indices and positions.
- `landmarks.png` holds the lesson and trail props. Source regions are defined in the game renderer.
- `terrain.png` uses 16 × 16 cells. From left to right, wet sand, water, left bank, right bank, solid ledge, drop-through bridge, crumbling ledge, and fence foundation.
- `effects.png` uses 32 × 32 cells. Six frames across, with warning, splash, and bubbles from top to bottom.
- `scratchy-swim.png` uses 48 × 32 cells. Six frames across, with paddle, tread, dive, and climb-out from top to bottom. These sprites are available for the future swimming controls.
